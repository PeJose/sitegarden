HOW ESTATES GROW · PLOT TEMPLATES

Three plot sizes, endless gardens

Every project gets the smallest plot its buildings fit in. The project’s seed picks the plot’s variant, rotation and mirroring, which slot each building takes, and where trees, beds and paths go in the space left over.

  1. 01 · SIZE
    Building count picks the smallest template that fits.
  2. 02 · SEED
    A hash of the project ID picks variant, rotation and mirroring, so it never changes.
  3. 03 · SLOTS
    Buildings fill slots in data-flow order; dragging one saves its slot.
  4. 04 · NEIGHBOURHOOD
    All seeds together generate the grey-green land around, drawn once and cached.
