# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button (Security tab, then Advisories). Do not open a public issue.

## Supported versions

Only the latest release is supported. The project is in early development.

## How sitegarden is meant to be deployed

See [docs/security-model.md](docs/security-model.md) for the deployment model and what sitegarden protects.
